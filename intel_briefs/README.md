# Intel Briefs

This directory contains structured YAML briefs generated by INTEL_AGENT
from real-world threat intelligence sources.

## Purpose

Intel briefs are the ground truth for how scenarios are built. They document:
- The adversary's attack chain mapped to MITRE ATT&CK
- The network topology conditions that enabled the attack
- The infrastructure involved, with lab substitutions noted
- The IOCs and artifacts staged in the scenario
- The operational dressing that makes the environment feel real

## Naming Convention

```
<adversary_or_topic>_<YYYY-MM-DD>.yaml
```

Examples:
- `volt_typhoon_ics_pivot_2025-06-01.yaml`
- `sandworm_industroyer_2025-07-15.yaml`
- `t1558_003_kerberoasting_2025-06-01.yaml`
- `cisa_aa23_049a_water_sector_2025-08-01.yaml`

Enrichment proposals:
```
enrichment_<scenario_name>_<YYYY-MM-DD>.yaml
```

## Committed to Git

Intel briefs ARE committed to git. They serve as:
1. Audit trail — why a scenario was built the way it was
2. Training documentation — traceable to real threat intelligence
3. Curriculum record — what adversary behaviors are covered
4. Version history — how scenarios evolved as new intel emerged
